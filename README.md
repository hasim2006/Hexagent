## 👥 The 6 Autonomous AI Employees

Hexagent replaces traditional business departments with autonomous, coordinated AI agents:

| Agent | Codename | Role | Core Capability |
| :--- | :--- | :--- | :--- |
| **Strategist** | `Aether` | Executive Strategy | Market trajectory modeling, company OKRs, vision alignment |
| **Hunter** | `Viper` | Revenue & Growth | Automated pipeline generation, outreach, enterprise conversion |
| **Creator** | `Echo` | Design & Content | Viral copywriting, brand identity, multi-platform media creation |
| **Automator** | `Nexus` | Systems & DevOps | Zero-touch workflow automation, API bridging & self-healing scripts |
| **Guardian** | `Aegis` | Security & Compliance | Threat monitoring, vulnerability mitigation & audit trails |
| **Finance** | `Cipher` | Treasury & Capital | Real-time burn-rate optimization, automated unit economics & P&L |

## 🏗️ Domain-Driven Project Architecture

```
src/
├── components/
│   ├── ui/           # Design system primitives (GlassCard, MagneticButton, Loader, Section)
│   ├── visuals/      # 3D & canvas shaders (CityCanvas, HoloGlobe, LiveGraph, ParticleField, Waveform)
│   ├── landing/      # Public experience (Hero, Headquarters, CommandCenter, LiveNetwork, Metrics)
│   ├── workforce/    # Employee personas (Employees showcase, AIPod, AIThinking visualizer)
│   ├── dashboard/    # Executive OS (Dashboard, CEOBriefing, MasterCommand, LiveTerminal, VoiceToggle)
│   ├── workspaces/   # Dedicated interactive workspaces for all 6 AI Employees + WorkspaceShell
│   └── index.ts      # Unified component registry barrel exports
├── os/               # State management engine, boot sequence & Web Speech synthesis
├── data/             # AI employee registry & telemetry configuration
└── hooks.ts          # Reactive scroll, observer & animation hooks
```

## 🚀 Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/hasim2006/Hexagent.git
cd Hexagent
npm install
```

### 2. Development Mode
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
npm run preview
```
