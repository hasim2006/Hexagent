# Security Policy

## Reporting Security Issues

The Hexagent team takes security seriously. If you discover a vulnerability or potential security risk in Hexagent, please report it privately:

- **Email:** [juug25btech29109@jainuniversity.ac.in](mailto:juug25btech29109@jainuniversity.ac.in)
- **Subject:** `[SECURITY] Vulnerability Report - Hexagent`

Please include:
- A description of the issue and potential impact
- Steps or proof-of-concept to reproduce
- Any recommended remediation

We will acknowledge receipt within 48 hours and work on a prompt resolution.
